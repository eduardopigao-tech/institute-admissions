# Institute Admissions Portal

A professional entrance examination and admissions management portal built with modern web technologies.

## 📋 Overview

This repository contains the official admissions portal for the Institute's entrance examination program. The portal provides applicants with a centralized platform to submit applications, track their status, and stay updated with important announcements.

## ✨ Features

- **Online Application Submission** - Easy-to-use form for submitting admission applications
- **Application Status Tracking** - Real-time updates on application processing status
- **Exam Schedule Management** - View and manage exam dates and times
- **Document Upload** - Secure submission of required documents
- **Verification System** - Automated and manual document verification
- **Result Notifications** - Instant notification when results are declared
- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **24/7 Support** - Dedicated support for applicants

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection

### Installation

1. Clone this repository:
```bash
git clone https://github.com/eduardopigao-tech/institute-admissions.git
cd institute-admissions
```

2. Open `index.html` in your web browser or serve it through a local server:
```bash
# Using Python 3
python -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Using Node.js (if you have http-server installed)
http-server
```

3. Navigate to `http://localhost:8000` in your browser
